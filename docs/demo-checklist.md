# Demo checklist

1. Run `npm run seed` from `server`.
2. Log in as `company1@example.com`; show, create, or edit internships.
3. Search students and open a student profile.
4. Log in as `student1@example.com`; confirm profile views, eligible internships, and wishes.
5. Log in as `admin1@example.com`; confirm distribution is initially not run.
6. Run distribution and show the summary and results table.
7. Log in as a student again and show their assigned or unassigned final result.

All evaluation accounts use `Password123`.
